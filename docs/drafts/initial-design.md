## Alitiha Agent

- A pure cli version of https://github.com/caesar0301/Alithia, located at
  ../alithia-app.

- Create based on soothe agent, located at ../soothe/packages/soothe/. Involve
  soothe library as dependency and extend with more subagents. Current we have
  paperscout. we should also have paperlens subagent.

- Inherite all functionalties of alithia-app built in the alithia agent.

- Use sqlite to save data. working dir ~/.alithia/
